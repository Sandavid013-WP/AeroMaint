AeroMaint

AeroMaint es un sistema de gestión de mantenimiento aeronáutico desarrollado como proyecto académico del programa de Análisis y Desarrollo de Software del SENA.

Descripción

El proyecto busca facilitar la gestión y seguimiento de aeronaves, componentes, técnicos y actividades relacionadas con el mantenimiento aeronáutico.

Tecnologías utilizadas
HTML
CSS
JavaScript
React
MySQL
Git
Estructura del proyecto
Documentacion: documentos técnicos relacionados con el proyecto.
Evidencias: evidencias y entregables del desarrollo.
Base_de_Datos: archivos relacionados con la base de datos MySQL.
Control de versiones

El proyecto utiliza Git para realizar el control de versiones y registrar los cambios realizados durante el desarrollo de AeroMaint.
